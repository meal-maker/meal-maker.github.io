## [ATProto 默认公开数据模型引发隐私设计讨论](https://lukekanies.com/writing/building-on-atproto/) ⭐️ 8.0/10

Luke Kanies 的文章指出了 ATProto 公开数据模型带来的摩擦，引发了关于权限、隐私和去中心化应用设计的深入讨论。 这场辩论揭示了协议开放性与用户隐私之间的关键设计矛盾，将影响去中心化社交应用的未来发展，波及开发者与用户。 关键细节包括当前提案中基于 URI 的位置权限方案，以及社区共识认为默认私密数据会破坏 ATProto 的公共读取共享架构。

hackernews · speckx · 7月23日 18:23 · [社区讨论](https://news.ycombinator.com/item?id=49025984)

**背景**: AT 协议（atproto）是支撑 Bluesky 的去中心化协议，设计采用公共数据和自认证记录以实现互操作性。它使用联邦模型和用户拥有的个人数据服务器（PDS），所有数据默认公开，除非添加访问控制。这与 ActivityPub 通常的有限共享模式形成对比。

## [LearnOpenGL：权威的现代 OpenGL 教程资源](https://learnopengl.com/) ⭐️ 8.0/10

LearnOpenGL 教程在 Hacker News 上被重点推荐为学习现代 OpenGL 不可或缺的高质量资源，获得社区高度赞誉和 8.0/10 的高分。 它为图形编程这一学习曲线陡峭的领域提供了清晰、循序渐进的入门路径，对有抱负的游戏开发者和图形工程师至关重要。它的持久价值突显了掌握基础概念比追逐最新 API 更重要。 该教程涵盖现代 OpenGL（3.3 以上版本），包括着色器、光照和模型加载，并配有详细解释的代码示例。社区成员指出，尽管 OpenGL 被认为是较旧的 API，但这些技能可迁移至 Vulkan 或 CUDA 等新技术。

hackernews · ibobev · 7月23日 14:53 · [社区讨论](https://news.ycombinator.com/item?id=49022634)

**背景**: OpenGL 是一个跨语言、跨平台的应用程序编程接口，用于渲染二维和三维矢量图形。现代 OpenGL 从 3.3 版开始引入了可编程渲染管线，开发者需用 GLSL 编写着色器来控制 GPU。由于图形编程的复杂性，像 LearnOpenGL 这样全面的教程对于新手在转向更底层或更高级 API 之前建立扎实的理解至关重要。

**社区讨论**: 评论压倒性地称赞该教程为“图形编程的圣经”。一些用户建议从软件渲染器入手以夯实基础，另一些则推荐使用 Sokol 或 SDL_GPU 等辅助库进行实际应用。多位开发者分享了该教程如何让他们最终理解复杂着色器概念的个人经历，还有人称图形编程是对日常 Web 开发工作的一种“疗愈”。

**标签**: `#graphics programming`, `#OpenGL`, `#tutorial`, `#computer graphics`, `#educational resource`

98.css 是一个纯 CSS 库，忠实再现了 Windows 98 的用户界面，其作者将其作为摆脱倦怠的疗愈项目分享，重新引起了开发者的兴趣和怀旧赞赏。 它重新引发了关于复古 UI 设计以及灰色禁用按钮等清晰功能可见性丧失的讨论，与现代扁平化设计趋势形成对比，并反映出对早期计算美学日益增长的怀旧情绪。 该库使用语义化 HTML 和纯 CSS，不依赖 JavaScript，包含按钮、窗口、标题栏和状态栏等组件。作者记录了该项目在帮助他从倦怠中恢复过来方面的个人反思。

**社区讨论**: 作者分享说这个项目是他摆脱倦怠的努力。评论者称赞灰色禁用按钮是一种已失落的 UI 功能可见性，表达了使用该库的愿望，并提到了其在 Hacker News 上过往的高热度。一位用户提到了一个相关的 Windows XP 主题 Linux 桌面项目。

## [手写对大脑有益](https://nealstephenson.substack.com/p/writing-by-hand-is-good-for-your) ⭐️ 7.0/10

尼尔·斯蒂芬森在 Substack 上发布文章，认为手写能增强大脑活动和学习，引发了对笔记方法的广泛讨论。 这加剧了关于数字学习工具与模拟学习工具的持续辩论，可能影响学生和专业人士进行笔记和知识记忆的方式。 文章指出数世纪的书写工具校准创造了最佳摩擦力，但怀疑者质疑大脑活动增加是否一定改善学习，也有人为 iPad 书写的适应性辩护。

**背景**: 长期以来，研究表明手写可能比打字更有助于记忆和理解，可能是因为运动参与和较慢的速度。随着笔记本电脑和平板电脑在教育中的普及，这一争论愈发激烈。
