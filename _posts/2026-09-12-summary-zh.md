### [GitLab 紧急修复 CVSS 10.0 未授权任意文件读取漏洞](https://docs.gitlab.com/releases/patches/patch-release-gitlab-19-3-2-released/) ⭐️ 8.0/10

GitLab 于 9 月 10 日发布 19.3.2、19.2.6 和 19.1.8 紧急补丁，修复编号为 CVE-2026-85706 的 CVSS 10.0 漏洞。该漏洞在特定条件下允许未认证用户利用代码仓库 commits API 的路径约束和认证缺陷，读取 GitLab 服务器上的任意文件。受影响范围包括 18.7 至 19.1.8 之前版本、19.2.6 之前的 19.2 版本以及 19.3.2 之前的 19.3 版本。GitLab 强烈建议自建实例立即升级至对应修复版本；GitLab.com 已完成修复，GitLab Dedicated 用户无需操作。漏洞由研究员 s3ntago 通过 HackerOne 报告，目前官方未公开具体前置条件，网上未出现可复现的公开 PoC，尚无证据表明已遭在野利用。

telegram · zaihuapd · 9月11日 11:05

**「背景」** GitLab Community Edition \(CE\) 和 Enterprise Edition \(EE\) 是广泛用于自托管代码托管与 DevOps 的平台。其 commits API 允许以编程方式访问仓库提交信息，而 CVSS 10.0 表示最高严重等级。此次漏洞涉及提交 API 的路径约束和认证缺陷，使未认证攻击者可能读取服务器上的任意文件。

**「影响」** 自建 GitLab 版本在 18.7 至 19.1.8 之前、19.2.6 之前 19.2、19.3.2 之前 19.3 的用户需立即升级到对应修复版本，否则可能被未授权读取服务器上的任意文件。

### [OpenAI 推出 Agents API 公测版](https://openai.com/index/introducing-the-agents-api/) ⭐️ 8.0/10

OpenAI 于 2026 年 9 月 10 日推出 Agents API 公测版，开发者可通过一次 API 调用创建生产级云端智能体，并选择 OpenAI 托管沙箱、自有基础设施或合作伙伴环境运行。该 API 基于开源 Codex harness，支持长会话上下文压缩、工具搜索、并行工具调用和子智能体协作。公测期间不额外收费，开发者只需按智能体使用的令牌和工具付费。此举降低了构建生产级 AI 智能体的门槛，使云端代理开发更简化。

telegram · zaihuapd · 9月11日 11:12

**「背景」** OpenAI 的 Codex harness 是一个开源编排框架，此前开发者主要通过 Codex CLI 或 SDK 使用它来构建可执行多步骤任务的 AI 智能体，需要自行处理会话管理、上下文压缩和故障恢复。Agents API 将这一 harness 作为 OpenAI 托管的服务暴露给开发者，由 OpenAI 负责管理会话、编排、上下文压缩和恢复，开发者只需提供工具并选择执行环境。

**「影响」** 对于需要构建生产级云端智能体的开发者，Agents API 公测版可直接通过单一 API 调用部署，并只需支付令牌和工具使用费用，无需为代理编排额外付费。

### [EPA 拟取消数据中心污染许可公众审查](https://capitalbnews.org/data-centers-permit-rules-epa/) ⭐️ 7.0/10

据报道，美国环保署（EPA）正计划取消数据中心污染许可的公众审查要求。这一变化将影响数据中心等科技基础设施项目的审批流程，可能加快项目推进。由于数据中心是 AI 和云计算扩展的关键设施，此举被认为与环境合规的公众监督削弱有关。评论者指出这与 EPA 被削弱、无法有效监管的背景一致，并引发对环境恶化的担忧。

**「背景」** 美国联邦环保署（EPA）此前要求各州在批准工业设施的空气污染许可申请前，必须向公众公布信息并征求意见，这些设施包括数据中心以及为其供电的发电厂。特朗普政府提出的变更拟取消这一披露与公众评议要求，使相关许可流程不再经过公开审查环节。

**「影响」** 该提案若实施，数据中心等“次要空气污染源”可在不公示的情况下获得空气污染许可，从而可能规避主要污染源管控，并削弱社区对 AI 基础设施扩张的反对能力。

**「社区讨论」** 社区评论普遍批评这一举措，认为 EPA 已被严重削弱、监管能力下降，并担忧数据中心扩张对环境造成破坏；也有观点认为支持与反对双方都面临时间压力，矛盾可能进一步激化。

### [单 GPU 训练 210M 文生图 DiT 的实测发现](https://www.reddit.com/r/MachineLearning/comments/1wdfmvq/training_a_210m_texttoimage_dit_from_scratch_on/) ⭐️ 7.0/10
